# KISS / Karpathy Guidelines

- Smallest correct solution. No speculative generality.
- No abstractions without 3 concrete uses.
- Tests for invariants before features.
- Readable > clever.
- Don't add config/flags "just in case".
- Prefer standard library; add deps only when justified.
- Mock over integrate for POC.
- Document production target (Rust, Kafka, K8s) as future, not now.
